# DeepSeek Chat на Rust

Полноэкранный чат для терминала, перенесённый с Gleam на Rust: лента сообщений,
редактируемая строка ввода, индикатор ожидания и multi-turn история диалога.

## Требования

- Rust 1.85 или новее (edition 2024)
- API-ключ DeepSeek

## Запуск

```sh
export DEEPSEEK_API_KEY=ваш_ключ
cargo run --release
```

Введите сообщение и нажмите `Enter`. Для выхода используйте `Esc` или `Ctrl+C`.
История прокручивается стрелками `↑/↓`, клавишами `PageUp/PageDown` или колёсиком
мыши. `End` возвращает к последнему сообщению. Пока история находится внизу,
новые части потокового ответа автоматически остаются в поле зрения.

Ответы DeepSeek отображаются как Markdown: поддерживаются заголовки, жирный и
курсивный текст, зачёркивание, ссылки, списки, цитаты, inline-код, блоки кода,
таблицы и task lists. Под текущим ответом находится индикатор с прошедшим
временем, например `DeepSeek отвечает (2m 13s)`.

Ответ формируется и обновляется в ленте в реальном времени через SSE-стриминг.

Остальные настройки также открываются без аргументов:

- `/format` — меню Text, JSON, Markdown и YAML; после выбора JSON, Markdown или
  YAML открывается второй попап для ввода схемы либо шаблона;
- `/limit` — попап для числа, `default` или `off`;
- `/stop` — попап для последовательности или `off`.

Старый краткий синтаксис с аргументами тоже поддерживается:

- `/format text` — обычный текст;
- `/format json <схема>`, `/format markdown <шаблон>` или `/format yaml <схема>`;
- `/limit <число>|default` — лимит токенов (`off` также выключает лимит);
- `/stop <последовательность>|off` — stop sequence.

Команды применяются локально и не добавляются в историю. По умолчанию
используется модель `deepseek-v4-flash`. Модель и адрес API можно переопределить:

```sh
export DEEPSEEK_MODEL=deepseek-v4-pro
export DEEPSEEK_API_URL=https://api.deepseek.com/chat/completions
cargo run --release
```
